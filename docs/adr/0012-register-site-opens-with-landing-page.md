# 報名網站打開是報名入口頁，大會介紹交給大會網站

> 取代 [ADR 0010](0010-homepage-opens-with-hero-and-status-bar.md)。

2026-11-09 決定，大會網站（首頁、大會介紹、籌備委員會等）由其他人在 `www.taiwanwomensconference.org` 負責，這個 repo 只做報名系統，搬到 `register.taiwanwomensconference.org`（#123）。報名網站的 `/` 不再是 ADR 0010 的大會首頁，改成簡單的**報名入口頁**（#125）：

大會名稱與年度 → 大會日期與時間 → 報名狀態 → 我要報名、幫家人或朋友報名、查詢或修改報名 → 到大會網站的連結 → 頁尾。

- 報名狀態依時期切換，日期都來自後台的報名開放、截止時間：報名前寫開放與截止時間，沒有任何按鈕（還沒有人報名，也不能查）；報名中寫截止時間，三個按鈕都在；已截止說明網站上不能修改或取消，只剩「查詢我的報名」。
- 沒有主視覺、選單與全站表頭；上方和報名表、查詢頁一樣只有語言切換。公告上線前照舊只顯示「大會資訊即將公布」。
- 後台的預覽（`/preview`）顯示同一頁，公告上線前也看得到，報名按鈕連到預覽報名表。

姐妹多半是從支會 LINE 群組點連結進來，目的就是報名或查詢。大會介紹、程序已經有大會網站，報名網站再放一份會有兩個地方要維護、內容不一致；入口頁只留報名要用的資訊，第一屏就是按鈕，回到 `docs/decisions-2026-10-06.md` 第 1 點「第一屏要有最大的我要報名按鈕」的精神。想看大會介紹的人點連結到大會網站。

## Considered Options

- **`/` 直接開報名表**：少按一次，但「幫家人或朋友報名」與「查詢或修改」沒有入口，報名前、已截止時也要有地方說明狀態。
- **保留 ADR 0010 的大會首頁**：大會介紹與大會網站重複，兩邊都要更新；主視覺與大會內容排在報名前面，手機第一屏只剩狀態列上的一顆按鈕。

## Consequences

- 375×667 的手機與 LINE 內建瀏覽器上，第一屏要看得到報名狀態與「我要報名」（報名中），中英文都要確認；英文的大會名稱較長，所以標題用小一號的字、不放全站表頭。改版面時要再確認一次。
- 舊首頁的主視覺、歡迎詞、大會有什麼、大會程序、常見問題、自訂區塊，以及籌備委員會網站、大會特色介紹頁，程式與後台編輯頁都移除（#126）；舊網址 `/committee`、`/highlights` 暫時轉址（307）到大會網站。資料表與已經填的資料先留著，之後確定大會網站不需要再另外清。
- 後台「首頁內容」只留報名要用的兩區，改名「大會時程」（`/staff/schedule`）：公告上線、報名開放、報名截止，以及大會日期與開始、結束時間。
- 管理員 LINE 整個拿掉（原本就隱藏），求助一律請姐妹問所屬支會或分會的慈助會會長。
- 複製新年度不再複製舊首頁與籌備委員會的內容，課程不帶分類；後台不再編輯課程的分類與場地的地址、場地特色，存檔時原本的資料不動。
- 分享到 LINE 的標題、說明與預覽圖都改成報名網站（`src/app/layout.tsx`、`scripts/og-image.html`）。

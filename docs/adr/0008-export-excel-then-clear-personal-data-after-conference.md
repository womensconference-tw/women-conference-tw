# 大會結束後匯出 Excel，確認存好再清除個資

取代 [ADR 0005](0005-anonymize-registrations-six-months-after-conference.md)。

籌備委員會習慣在大會結束後拿一份 Excel 名單做核對與致謝，之後就不需要資料庫裡的個資。所以不再等 6 個月：大會結束後，總管理員隨時可以下載該年度的 Excel 名單，下載完確認「檔案已存好、打得開」，再按一次才清除個資。下載與清除分成兩步，是為了避免下載失敗時資料已經被清掉、再也找不回來。

清除後該年度的報名不刪除，只移除可認出本人的資料，留下的欄位讓舊年度統計仍可檢視。這裡的「匿名化」指本系統移除直接識別資料；留下的支會、課程等選擇仍可能和 Excel 交叉比對，所以不宣稱完全無法識別。

## 大會結束的時間點

年度大會只記日期，沒有結束時間，所以「大會結束」定為大會日期翌日的台北時間 00:00。不是報名截止。

## Excel 欄位

年度 Excel 是給籌備委員會核對與致謝用的名單，不是統計資料的完整匯出（不含支聯會、支會、已取消的報名）。

工作表「名單」一列一筆有效報名（已取消的不列），依場地排序。欄位順序沿用舊系統的試算表：

姓名、參加教堂、報名語言、午餐、第一場次課程、午后動態、第二場次課程……第 N 場次課程、類別（身分類別）、即席唱詩班、事前準備志工、翻譯人員、當天接待志工、事後復原志工、是否要紙本手冊。

- N 是該年度場次最多的場地的場次數。各場地依自己的場次順序填入第 1 至 N 欄；成對課程兩個場次分別填同一門課。
- 儲存格文字固定：有該場次但沒選課填「不選課」，場地沒有這個場次填「不適用」；有午后動態但沒參加填「不參加」，場地沒有午后動態填「不適用」；午餐沒選填「不需要」；即席唱詩班填「女高音」「女低音」或「不參加」；四種志工填「是」或「否」；紙本手冊填「需要」或「不需要」；報名語言填 zh 或 en。
- 另一個工作表「場次對照」列出每個場地的第 1 至 N 場次實際名稱與時間。
- 不含電話、Email、LINE ID、報名編號、支聯會、支會。
- 沒有有效報名的年度也可以下載，檔案只有表頭，流程照常。

## 下載、確認、清除

- 只有總管理員能下載與清除，且只能在大會結束之後；伺服器端檢查，不靠畫面隱藏。
- 系統記下每次下載該年度 Excel 的時間。清除前總管理員必須勾選「Excel 已存好、打得開」；確認綁在該年度最近一次下載上。下載之後該年度任何報名有新增、修改或取消，那次下載就失效，必須重新下載並確認。下載其他年度不算。
- 確認畫面分別顯示「Excel 內的有效報名 N 筆」與「將清除個資的報名 M 筆（含已取消）」。
- 清除涵蓋該年度全部報名（含已取消）及其寄信紀錄，在同一個交易內完成：中途失敗就全部回復、不記清除時間，可以重試。已清除過再按，回傳已完成，清除時間不變。
- 清除與匯出不能交錯：不會產生一半有姓名、一半已清除的 Excel。
- 清除後，該年度不能再下載 Excel、不能補寄信、不能新增或修改報名個資；統計仍可檢視。

## Consequences

- 清除的欄位：姓名、電話、報名編號、Email、LINE ID、送出時使用的電話；寄信紀錄裡的收件地址，以及任何含姓名或聯絡方式的信件內容、錯誤回應、重試資料。之後新增含個資的欄位或資料表時，必須一起納入清除。
- 保留的欄位：內部識別碼與所屬年度、場地、支聯會、支會、課程、午后動態、午餐、服務意願、紙本手冊、身分類別、報名語言、狀態、肖像權同意時間、取消時間、建立與修改時間。另記清除時間。不可還原。
- 目前報名資料表要求姓名不可空白、電話與報名編號必須有一個。實作時要改成：已清除的報名允許這些欄位全部為空，未清除的報名仍維持原本的驗證規則。
- 不自動執行、也不設 6 個月提醒；什麼時候做由總管理員決定。
- 清除之後，需要姓名的工作只能靠那份 Excel，所以檔案要存在只有籌備委員會能存取的地方，不能放進公開的 repo。
- 報名時要記下報名語言（送出當下使用中文或英文畫面），必填。新增這個欄位前已存在的報名一律補為 zh。確認信也依這個語言寄送。
- 年度 Excel 與 [ADR 0004](0004-staff-roles-scoped-by-venue-and-stake.md) 的範圍內名單匯出、名牌 CSV 是不同的東西：後兩者的權限與時程照原規格，承辦人員仍可匯出自己範圍內的資料。

# 首頁第一屏是主視覺，報名入口是狀態列的「前往報名」

首頁照美編組的設計稿（`docs/design/`）排：Header → 主視覺 → 狀態列 → 歡迎詞 → 大會有什麼 → 大會程序 → 報名參加 → 常見問題 → 需要幫忙 → 自訂區塊 → Footer，手機與電腦相同。第一屏是年度主視覺，緊接著的狀態列寫大會日期、時間、三地同步與報名狀態；報名中有「前往報名」、已截止有「查詢我的報名」，都是捲到下面的「報名參加」區，報名三步驟、我要報名、幫家人或朋友報名、已報名查詢都在那一區。這取代 `docs/decisions-2026-10-06.md` 第 1 點「第一屏要有最大的我要報名按鈕」與原本的區塊順序（2026-10-20 決定，#80、#85）。

原本把報名放在最上面，是因為舊網站的報名按鈕在最底部，姐妹找不到。新設計把大會內容（主視覺、大會有什麼、大會程序）放在報名前面，姐妹先知道有哪些課程、要去哪間教堂，再報名；報名入口仍在第一屏，只是從「最大的按鈕」變成狀態列上的一顆按鈕。「前往報名」捲到報名區而不是直接開報名表，姐妹會先看到三步驟、代報和查詢，再選要按哪一個（2026-10-21 確認）。

## Considered Options

- 維持原本的順序，主視覺放在報名下面：第一屏最大的是報名按鈕，但美編組的主視覺與大會內容被推到很下面，和設計稿不同。
- 狀態列的「前往報名」直接開報名表：少按一次，但跳過三步驟的說明，也看不到「幫家人或朋友報名」的入口。

## Consequences

- 375×667 的手機與 LINE 內建瀏覽器上，第一屏要看得到狀態列和「前往報名」；主視覺高度最多是一屏扣掉 Header 與狀態列第一行，狀態列裡報名狀態與按鈕排在日期上面（設計稿相反）；改主視覺或狀態列的版面時要再確認一次。
- 報名狀態只在狀態列與報名區兩個地方顯示，日期都來自後台的報名開放、截止時間。
- 原本的「大會場地」區拿掉，教堂的地址與地圖改在大會程序選好教堂後顯示；後台「場地特色」首頁不再顯示（欄位保留）。

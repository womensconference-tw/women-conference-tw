# 姊妹大會活動介紹頁：設計交接說明

> 2026-10-24：活動頁版型已改為 4 個共用範本，見 `activity-templates-handoff.md`。本文件的人物卡片規格與 2026 資料仍可參考。

給 Claude Code 實作用。適用三個頁面：向貴賓致敬、與年長夫婦傳教士有約、靜態展示。

設計稿放在 `claude/design/`，三頁一頁一個檔案：
- `activity-honor.dc.html`：向貴賓致敬
- `activity-missionary.dc.html`：與年長夫婦傳教士有約
- `activity-exhibit.dc.html`：靜態展示

這些檔案是 Design 畫布的元件格式：版面在 `<x-dc>` 裡，資料在最下面 `<script type="text/x-dc">` 的 `renderVals()`。實作時請照版面與樣式改寫成 Next.js 元件，不要直接沿用這個格式。

視覺規格（字型、顏色、字級、按鈕高度）和首頁相同，以 `claude/design/homepage-handoff.md` 的「視覺規格」為準。已定案的規則見 `claude/姊妹大會重寫_已定案決定.md`。

## 共用版型（三頁共用同一個元件）

建議做成一個 `ActivityPage` 版型，三頁只差資料。

1. **Header**：網站名稱（連回首頁）、主選單（認識大會／大會程序／報名與查詢）、English 按鈕。和首頁相同。
2. **麵包屑**：首頁 › 大會有什麼 › 〔活動名稱〕。每個連結高度至少 44px。
3. **標題區**：小標「大會有什麼」（主色）、H1 活動名稱（Noto Serif TC 40px）、一句副標。
4. **介紹區**（淺底 `#F2F0E8`）：左邊一段放大的引言（明體 26–28px），右邊是內文段落。寬度不夠時自動上下排（flex-wrap）。
5. **人物區**：H2 加一句說明，下面是卡片格線。
6. **Footer**：和首頁相同。

**刻意不放的東西**（Lisa 已確認）：時間、地點、怎麼參加、報名按鈕、「大會還有」連結。頁面只放介紹和人物，以及每個人對應的連結。

## 人物卡片

- 格線：`grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))`，gap 20px。傳教士頁卡片較少，用 `minmax(300px, 1fr)`。
- 卡片：白底、邊框 `#E4E1D6`、圓角 18px，內容置中。
- 由上到下：
  1. 圓形照片：180px，傳教士頁 220px。
  2. 「支聯會・支會」：16px，次要文字色。
  3. 姓名：明體 24px／700。
  4. 連結按鈕：靠卡片底部（`margin-top: auto`），寬度撐滿，高度至少 52px。
- 連結按鈕文字：
  - 向貴賓致敬：「閱讀她的故事」（外框按鈕）
  - 傳教士：「認識這對傳教士」（外框按鈕）
  - 靜態展示：直接顯示**作品名稱**，淺底按鈕，右側有 › 符號
- 手機：卡片一欄，左右留白 20px。

## 照片（重要）

- 設計稿裡的照片是從舊網站截圖裁下來的，已經被切成圓形，畫質也偏低，**只能當示意**。
- 正式網站請用**原始的長方形照片**，用 `width/height 固定 + border-radius: 50% + object-fit: cover` 顯示成圓形。
- 舊網站有些照片的頭或下巴被切掉。請在後台幫每張照片加一個「對焦點」欄位（上／中／下，或 0–100%），對應 `object-position`，讓管理員自己調整。
- `alt` 用姓名。

## 資料結構建議（掛在年度底下）

`activity_people`：
- `activity`：`honor` | `missionary` | `exhibit`
- `sort_order`
- `stake`（支聯會）、`ward`（支會／分會）
- `name_zh`、`name_en`
- `photo_url`、`photo_focus`（object-position）
- `link_label_zh`／`link_label_en`：靜態展示放作品名稱；其他兩頁可以留空，用預設文字
- `link_url`：個人或作品介紹頁

`activities`（每頁一筆）：`slug`、`title_zh/en`、`subtitle_zh/en`、`lead_quote_zh/en`、`lead_quote_source`、`body_zh/en`（多段文字）。

依已定案的方向，文字和人物都要能從後台修改。英文版要完整對應中文版。

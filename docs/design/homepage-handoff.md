# 姊妹大會首頁：設計交接說明

給 Claude Code 實作用。設計稿：`homepage-mobile.dc.html`（手機，主要）、`homepage-desktop.dc.html`（電腦）。
兩個檔案是 Design 畫布的元件格式：版面在 `<x-dc>` 裡，資料與互動邏輯在最下面的 `<script type="text/x-dc">`。實作時請照版面與樣式重寫成 Next.js 元件，不要直接沿用這個格式。

已定案的規則見 `../decisions-2026-10-06.md`，本文件不重複。

## 全站表頭與頁尾（2026-10-24 更新，首頁與活動頁共用）

- 表頭選單：認識大會、大會程序、大會場地、報名與查詢、致謝、English。首頁電腦版另保留「聯絡管理員」錨點。
- 不用下拉選單。
- 手機（≤640px）：表頭只留「報名與查詢」與 English（首頁手機版只留 English，報名入口在狀態列）。其餘項目放頁尾。
- 頁尾：一排完整選單連結（手機兩欄），每個點擊目標 ≥ 44px。

## 區塊順序

1. Header：見上方「全站表頭與頁尾」
2. 年度 Banner：後台上傳圖片（含經文）。手機 4:5（1080×1350）、電腦 3:1（2400×800），中英各一組，並有「圖片說明」欄位作為 alt 文字
3. 狀態列：日期、時間、三地同步＋報名狀態與「前往報名」（錨點到 #register）
4. 歡迎詞（#about）
5. 大會有什麼：分類卡片（即席唱詩班、領袖演講、靈性課程、角落課程、迷妳音樂會、向貴賓致敬、與年長夫婦傳教士有約、公益服務、靜態展示）
6. 大會程序（#agenda）：選教堂 → 地址＋地圖 → 時間軸
7. 報名參加（#register）：狀態、三步驟、我要報名、幫家人或朋友報名、已報名查詢
8. 需要幫忙（#help）：管理員 LINE
9. Footer：網站名稱、頁尾選單、回到最上面

## 三種時期（依後台設定的開放／截止時間自動切換）

| 時期 | 狀態列 | 報名區 |
|---|---|---|
| before 報名前 | 「12月26日開放報名」 | 藍色說明卡，不顯示按鈕、不顯示查詢 |
| open 報名中 | 「報名中・截止 1/13」＋前往報名 | 綠色狀態、三步驟、我要報名、幫家人報名、查詢或修改 |
| closed 已截止 | 「報名已截止」＋查詢我的報名 | 褐色說明卡、查詢我的報名 |

## 大會程序

- 三個教堂的時段與順序相同，場次內容不同。
- 選教堂：三個大按鈕（不用下拉選單），`aria-pressed` 標示目前選擇。
- 時間軸各列：

| 時間 | 項目 | 備註 |
|---|---|---|
| 08:30–09:15 | 報到 | |
| 09:30–10:30 | 開幕式 | 子項目：即席唱詩班、80 歲年長貴賓、領袖演講；顯示各教堂地點 |
| 11:00–11:50 | 第一場次 | 選一門 |
| 11:50–12:30 | 午餐聯誼 | 大雅顯示 3F 康樂廳 |
| 12:30–13:15 | 公益服務說明 | 金華另有午后動態「聲之靜·心之境」（三樓大會堂，名額有限） |
| 13:30–14:15 | 第二場次 | 選一門 |
| 14:30–15:15 | 第三場次 | 選一門 |
| 15:30–16:30 | 閉幕式 | 子項目：見證、領袖演講 |

- 場次列：課程依分類分組，每門課顯示課名、講師、教室；連續兩堂的課加註。手機版預設只展開第一場次，其他用「看 N 個選項」按鈕展開；電腦版預設全部展開。
- 資料以《廠商_20260203_final.xlsx》為準（課名、教室、時間）。講師與分類取自 2026 程序表。完整資料在設計檔 script 的 `VENUES` 物件。

## 資料結構建議（都掛在年度底下）

- `agenda_items`：sort_order、start、end、title_zh／title_en、kind（`shared`｜`session`）、session_no、parts（子項目陣列）
- `agenda_item_venues`：agenda_item_id、venue_id、place、alt_note（例如金華的午后動態）
- `courses`：venue_id、session_no、category、title_zh／title_en、speaker、room、capacity、pair_with（連續兩堂）
- 議程的場次內容直接讀 `courses`，和報名表單、名牌背面共用同一份資料。

## 視覺規格

- 字型：Noto Serif TC（標題 600/700）、Noto Sans TC（內文 400/500/700）
- 顏色：底 `#FBFAF6`、文字 `#1E2420`、次要文字 `#4A524C`、主色 `#355227`（白字對比 8.8:1）、分隔 `#E4E1D6`、淺底 `#F2F0E8`、藍色區塊 `#EAF1FA`
- 狀態色：報名中 `#E3EED8`／`#2C4620`、報名前 `#EAF1FA`／`#1F3F66`、已截止 `#F5EBE3`／`#6E3510`
- 內文 19px，行高 1.7；主按鈕高 64px，其他按鈕 52–58px，所有點擊目標 ≥ 44px
- 手機左右留白 20px；電腦版內容最寬 1120px
